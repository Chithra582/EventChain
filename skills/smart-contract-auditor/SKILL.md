# Smart Contract Auditor Skill

## Overview
Reviews ticketing smart contracts for reentrancy vulnerabilities, gas optimization, and standard compliance.

## Operations
1. Audits Solidity contract methods for reentrancy and integer safety.
2. Validates ERC-721 interface compatibility.
3. Checks circuit-breaker emergency pause mechanisms.
